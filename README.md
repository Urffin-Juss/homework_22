# Учебный проект: Интернет-магазин на Django

Проект создан в рамках обучения на курсе Python-разработчика.

## Технологии
- Python 3.10
- Django 4.2
- PostgreSQL
- HTML/CSS
- JavaScript

## Функционал
- Каталог товаров
- Корзина покупок
- Оформление заказов
- Регистрация пользователей
- Админ-панель

## Установка
1. Клонировать репозиторий
2. Создать виртуальное окружение
3. Установить зависимости: `pip install -r requirements.txt`
4. Запустить миграции: `python manage.py migrate`
5. Запустить сервер: `python manage.py runserver`
